康寧大學 資訊管理科 111級 實務專題實施計畫整理
一、 專題基本規定

學分數： 五年級上、下學期各一學分，合計二學分。

分組人數： 每組 3-4 位同學。

老師指導限額： 每位老師最多指導 2 組，額滿即不再受理。

資訊軟體開發組（系統組）

範疇： 系統開發。

技術要求：

需使用程式語言開發，並具備資料庫連結功能（如 Access, MS SQL, MySQL）。

不可僅有前端介面，必須實作後端資料庫管理。

不可與前4年的學長姐們的專題題目衝突到。

可以為某家公司做一個全新的系統或者寫一個全新網頁。可以為學校的系統做優化與改良，但必須說明怎麼證明自己的系統比現有的好，同時修改的份量要超過現有的系統60%。

審查重點：

需提供系統提案書（System Proposal）。

期中進度需達 70%（原訂 80%，經老師修正為 70%）。

文件需包含：系統需求、分工表、系統架構圖、ERD（實體關聯圖）、資料字典（Data Dictionary）。

資料庫至少需有 6 個資料表以上。

系統使用者角色至少需有 3 種（含管理員，不含訪客）。

具備基本的資料正規化及防呆設計。

商務網站經營組（商管組）

行銷企劃類：

需撰寫完整行銷企劃書（包含 PEST 分析、競爭者分析、SWOT、STP、4P 分析）。

### 6.3 AI Agent 不可直接做什麼

- 不可直接修改正式畢業門檻。
- 不可直接判定學生畢業或不及格。
- 不可沒有來源就補寫校方規定。
- 不可將搜尋結果直接發布成正式規則。
- 不可讀取需要帳號密碼的私人資料，除非學校正式授權介接。

人工確認流程：

```text
Agent 蒐集來源 → 產生草稿 → 顯示來源與差異 → 管理員／科辦確認
→ 發布正式版本 → 保留發布人、時間與原始來源
```
