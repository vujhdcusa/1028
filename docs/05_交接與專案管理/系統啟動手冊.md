# 資管科智慧學習歷程系統 — 系統啟動手冊

適用版本：小組 repo `main` 與 `feat/google-docs-autobiography`（2026-10-21 起兩者同步，首頁標語「把五年，拼成下一站」）。
給第一次接觸的組員：只想快速打開，看第三節「一鍵啟動」即可；遇到問題看第八節。更口語的步驟版見 [組員開啟說明.md](組員開啟說明.md)。

## 一、系統組成

| 元件 | 說明 | 位置／埠號 |
| --- | --- | --- |
| 資料庫 | XAMPP 內附的 MySQL（MariaDB 10.4） | `127.0.0.1:3306`，資料庫 `smart_learning_portfolio` |
| 後端 | Python Flask 3（含 Jinja2 模板） | 專案資料夾 `app\` |
| 網頁 | 瀏覽器開啟後端網址 | `http://127.0.0.1:5013` |
| 設定檔 | `.env`（每人自己一份，不提交） | 專案根目錄 |

## 二、事前準備（每台電腦只做一次）

1. **Python 3.12 或 3.13**：https://www.python.org/downloads/ ，安裝第一頁務必勾選「Add python.exe to PATH」。
2. **XAMPP**：https://www.apachefriends.org/ ，建議裝在預設的 `C:\xampp`（腳本會找 C:～G: 的 `\xampp`）。只用到 MySQL，Apache 不必開。
3. **Git**：https://git-scm.com/download/win ，一路「Next」。
4. 取得專案：在要放專案的資料夾按右鍵 →「Open Git Bash here」，執行

   ```bash
   git clone https://github.com/LanyuLiu951127/smart-learning-portfolio.git
   ```

   預設分支 `main` 已和 `feat/google-docs-autobiography` 同步；加不加 `-b feat/google-docs-autobiography` 都是同一版。資料夾放哪裡都可以，所有腳本都用相對路徑。
5. 點兩下專案根目錄的 `create_desktop_shortcut.bat`，桌面會出現「資管科學習歷程」捷徑。專案資料夾搬家後要重新點一次。

## 三、一鍵啟動（建議）

點桌面「資管科學習歷程」捷徑（或專案根目錄的 `start_system.bat`）。黑色視窗會依序做：

| 步驟 | 內容 | 什麼時候做 |
| --- | --- | --- |
| 0 | `git pull --ff-only` 拉目前分支的最新版（沒網路或自己改過檔案就略過） | 每次 |
| 1 | 找 Python | 每次 |
| 2 | 找 XAMPP；MySQL 沒開就啟動，最多等 30 秒 | 每次 |
| 3 | 建虛擬環境 `.venv`、安裝 `requirements.txt`（約 3～10 分鐘） | 第一次；之後 `requirements.txt` 有變才重裝 |
| 4 | 從 `.env.example` 複製出 `.env`，並把 `SECRET_KEY`、`DB_PASSWORD` 換成隨機值 | 第一次 |
| 5 | 用 XAMPP 的 root 建資料庫與專案帳號 `smart_learning_app` | 第一次 |
| 6 | 空資料庫：建資料表、標記遷移版本、建立 `admin`；已有資料：執行資料庫遷移 | 每次 |
| 7 | 啟動 Flask（5013 埠），可連線後自動開瀏覽器 | 每次 |

看到「系統網址：http://127.0.0.1:5013」且瀏覽器打開首頁就成功了。**黑色視窗不要關**，關掉就等於關掉系統。

### 確認開到的是正確版本

正確首頁：標語「把五年，拼成下一站」、畫面散落藍色資料夾、中間站著一個小人，右上角只有「五年路徑」「登入」。
若看到「五年，會留下很多東西。」加卡片拼貼、選單有「校系資料」，那是舊版：在專案資料夾執行 `git pull`，或重新 clone。

## 四、登入帳號

- 管理者：帳號 `admin`，密碼是 `.env` 的 `ADMIN_DEFAULT_PASSWORD`（預設 `admin123`，只在第一次建立 admin 時使用）。
- 學生、老師等帳號由管理者在系統內建立。
- 第五節的展示站另有合成帳號。

## 五、其他啟動方式

### 展示站（不用 MySQL，資料關掉就消失）

適合只看畫面、做簡報截圖。需先跑過一次一鍵啟動建立 `.venv`：

```bash
.venv\Scripts\python.exe scripts\run_local_demo.py
```

網址同為 `http://127.0.0.1:5013`（不能和一鍵啟動同時開）。合成帳號 `student_demo`／`teacher_demo`／`staff_demo`／`admin_demo`，密碼皆 `demo2026`。
可加參數：`--ocr` 用本機真實 OCR（需先執行 `.venv\Scripts\python.exe scripts\download_ocr_models.py` 下載模型）、`--gpu 1` 用顯示卡加速、`--google` 開放 Google 文件自傳（需在 `.env` 填 OAuth 設定）。

### 手動逐步啟動（除錯用）

```bash
.venv\Scripts\python.exe scripts\start_local.py
```

它做的是第三節的步驟 4～7，前提是 MySQL 已經在跑（可在 XAMPP Control Panel 按 MySQL 的 Start）。

## 六、停止與重新啟動

- 停止系統：關掉黑色視窗，或在視窗內按 `Ctrl + C`。
- 停止 MySQL：打開 XAMPP Control Panel，按 MySQL 的 Stop。不停也沒關係，下次啟動會直接沿用。
- 重新啟動：再點一次桌面捷徑。

## 七、可調整的設定（`.env`）

| 設定 | 用途 | 預設 |
| --- | --- | --- |
| `APP_PORT` | 系統網址埠號 | 5013 |
| `DB_PORT` | MySQL 埠號 | 3306 |
| `DB_NAME`／`DB_USER`／`DB_PASSWORD` | 資料庫名稱與專案帳號 | 第一次自動建立 |
| `MYSQL_ROOT_PASSWORD` | XAMPP root 有設密碼時才填 | 空白 |
| `ADMIN_DEFAULT_PASSWORD` | 第一次建立 admin 的密碼 | admin123 |
| `DOCUMENT_ANALYSIS_PROVIDER` | `fake` 模擬 OCR、`rapidocr` 本機真實 OCR | fake |
| `XAMPP_HOME`（系統環境變數） | XAMPP 不在 C:～G: 的 `\xampp` 時指定位置 | — |

`.env` 內含密碼，**不要傳給別人、不要提交**；要分享設定請改 `.env.example`。

## 八、常見問題

| 畫面訊息 | 處理方式 |
| --- | --- |
| 找不到 Python | 重裝 Python 並勾選「Add to PATH」（或安裝程式選 Modify 補勾）。 |
| 找不到 XAMPP | 安裝 XAMPP；裝在其他位置就新增系統環境變數 `XAMPP_HOME`。 |
| MySQL 30 秒內沒有啟動 | 開 XAMPP Control Panel 按 MySQL 的 Start 看紅字。常見是 3306 被另一套 MySQL 占用：停掉那套，或改 `.env` 的 `DB_PORT`。 |
| 無法用 root 連上 MySQL | XAMPP root 有密碼，在 `.env` 加 `MYSQL_ROOT_PASSWORD=密碼`。 |
| 已有帳號 smart_learning_app，但 DB_PASSWORD 登入失敗 | 把正確密碼填到 `.env` 的 `DB_PASSWORD`，或把 `DB_USER` 改成新名字讓腳本重建。 |
| 5013 埠已被其他程式使用 | 系統可能已開著，直接開網址；或關掉展示站；或 `.env` 加 `APP_PORT=5020`。 |
| 無法自動更新 | 沒網路或自己改過檔案，會先用目前版本啟動；需要最新版時先處理自己的修改再 `git pull`。 |
| 首頁是舊版 | 見第三節「確認開到的是正確版本」。 |
| 套件安裝失敗 | 多半是網路中斷，重新點一次；仍失敗就截圖黑色視窗給組長。 |
| 畫面出現資料表欄位錯誤 | 先 `git pull` 再重開（會自動遷移）；仍不行就在 `.env` 改 `DB_NAME` 建全新資料庫。 |
| 中文變亂碼 | 黑色視窗標題列右鍵 → 內容 → 字型改「Consolas」或「新細明體」，不影響功能。 |

## 九、哪些東西不會上傳 GitHub

`.env`、`.venv\`、`instance\`（上傳檔案、OCR 模型）、`logs\`、`__pycache__\` 都在 `.gitignore`，各自留在自己電腦。程式、模板、靜態檔、資料庫遷移、`requirements.txt` 與這些腳本都在 repo 裡。
