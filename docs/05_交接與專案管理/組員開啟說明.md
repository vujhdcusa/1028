# 組員開啟說明：一鍵啟動資管科學習歷程系統

clone 下來之後，點兩下 `start_system.bat`（或桌面捷徑）就會依序：拉最新版 → 啟動 XAMPP 的 MySQL → 建虛擬環境並安裝套件 → 建 `.env` → 建資料庫與資料表 → 啟動系統 → 自動開瀏覽器到 `http://127.0.0.1:5013`。

> **開發中的最新版在 `feat/google-docs-autobiography` 分支。** 2026-10-21 已把小組 repo 的 `main` 更新到同一版，但之後的新功能會先進這條分支。一鍵啟動只會更新「你電腦目前所在的分支」，所以請照第二節的指令 clone；已經 clone 過的人看第二節的「切換分支」。完整手冊見 [系統啟動手冊.md](系統啟動手冊.md)。

| 元件 | 說明 | 位置／埠號 |
| --- | --- | --- |
| 資料庫 | XAMPP 內附的 MySQL（MariaDB） | `127.0.0.1:3306`，資料庫 `smart_learning_portfolio` |
| 後端 | Python Flask 3（Jinja2 模板） | 專案資料夾 `app\` |
| 網頁 | 瀏覽器開啟後端網址 | `http://127.0.0.1:5013` |
| 設定檔 | `.env`（每人自己一份，不提交） | 專案根目錄 |

## 一、先安裝三樣東西（只要裝一次）

| 軟體 | 下載 | 注意 |
| --- | --- | --- |
| Python 3.12 或 3.13 | https://www.python.org/downloads/ | 安裝第一個畫面勾選「Add python.exe to PATH」 |
| XAMPP | https://www.apachefriends.org/ | 用預設位置 `C:\xampp` 最省事；只需要 MySQL，Apache 可不開 |
| Git | https://git-scm.com/download/win | 一路按「Next」即可 |

## 二、第一次開啟

1. 在想放專案的資料夾空白處按右鍵 →「Open Git Bash here」，貼上下面指令。**建議加上 `-b feat/google-docs-autobiography`**：不加會拿到 `main`，目前和這條分支同版，但之後可能落後：

   ```bash
   git clone -b feat/google-docs-autobiography https://github.com/LanyuLiu951127/smart-learning-portfolio.git
   ```

2. 進入 clone 下來的資料夾，點兩下 **`create_desktop_shortcut.bat`**，桌面會出現「資管科學習歷程」捷徑。
3. 點桌面捷徑（或直接點 `start_system.bat`）。第一次要下載套件，約需 3～10 分鐘，黑色視窗跑完會自動開瀏覽器。
4. 登入帳號：`admin`，密碼是 `.env` 裡的 `ADMIN_DEFAULT_PASSWORD`（預設 `admin123`）。學生、老師等帳號由管理者在系統內建立。
5. 用完直接關掉黑色視窗就停止系統。MySQL 會留在背景，要關可在 XAMPP Control Panel 按 MySQL 的 Stop。

之後每次只要點桌面捷徑。黑色視窗會做：

| 步驟 | 內容 | 什麼時候做 |
| --- | --- | --- |
| 0 | `git pull --ff-only` 拉目前分支的最新版（沒網路或自己改過檔案就略過，畫面顯示「無法自動更新」） | 每次 |
| 1 | 找 Python | 每次 |
| 2 | 找 XAMPP；MySQL 沒開就啟動，最多等 30 秒 | 每次 |
| 3 | 建虛擬環境 `.venv`、安裝 `requirements.txt`（約 3～10 分鐘） | 第一次；之後 `requirements.txt` 有變才重裝 |
| 4 | 從 `.env.example` 複製出 `.env`，並把 `SECRET_KEY`、`DB_PASSWORD` 換成隨機值 | 第一次 |
| 5 | 用 XAMPP 的 root 建資料庫與專案帳號 `smart_learning_app` | 第一次 |
| 6 | 空資料庫：建資料表並建立 `admin`；已有資料：執行資料庫遷移 | 每次 |
| 7 | 啟動系統（5013 埠），可連線後自動開瀏覽器 | 每次 |

看到「系統網址：http://127.0.0.1:5013」且瀏覽器打開首頁就成功了。**黑色視窗不要關**，關掉就等於關掉系統。

### 切換分支（已經 clone 過、但停在 `main` 的人）

在專案資料夾按右鍵「Open Git Bash here」，執行下面兩行，之後點捷徑就會一直拿到最新版：

```bash
git fetch
git switch feat/google-docs-autobiography
```

> **看到的首頁要是「把五年，拼成下一站」、畫面散落藍色資料夾、中間站著一個小人，網址 `http://127.0.0.1:5013`。** 如果看到的是「五年，會留下很多東西。」加卡片拼貼、選單有「校系資料」（以前用 `python run.py` 開在 5000 埠），那是 10-21 以前的舊版：照上面「切換分支」做，或照第 1 步的指令重新 clone。

> 專案資料夾搬家後，重新點一次 `create_desktop_shortcut.bat` 更新捷徑即可。所有路徑都是相對位置，放在哪個資料夾都能用。

## 三、哪些東西只在自己電腦（都不會被提交）

- `.venv\`：虛擬環境與套件。
- `.env`：自己的設定。第一次會從 `.env.example` 複製，並把 `SECRET_KEY`、`DB_PASSWORD` 換成隨機值。**不要把 `.env` 傳給別人或提交。**
- MySQL 裡的資料庫 `smart_learning_portfolio` 與帳號 `smart_learning_app`（用 XAMPP 預設、沒有密碼的 root 建立）。
- `instance\`：上傳的檔案（`uploads\`）與 OCR 模型（`ocr-models\`）。
- `logs\`：執行紀錄。

程式、模板、靜態檔、資料庫遷移、`requirements.txt` 與啟動腳本都在 repo 裡，`git pull` 就會更新。

## 四、常見問題

| 畫面訊息 | 原因與處理 |
| --- | --- |
| 找不到 Python | 沒裝或沒勾「Add to PATH」。重裝 Python 時勾選，或在安裝程式選「Modify」補勾。 |
| 找不到 XAMPP | 腳本只找 C:～G: 的 `\xampp`。裝在別處時，在系統環境變數新增 `XAMPP_HOME`（值是 XAMPP 資料夾），再重開腳本。 |
| MySQL 30 秒內沒有啟動 | 打開 XAMPP Control Panel 按 MySQL 的 Start，看紅字。最常見是 3306 埠被另一套 MySQL 占用：停掉那一套，或把 `.env` 的 `DB_PORT` 改成那一套的埠號並自行建好帳號。 |
| 無法用 root 連上 MySQL | XAMPP 的 root 被設了密碼。在 `.env` 加一行 `MYSQL_ROOT_PASSWORD=你的密碼`。 |
| 已有帳號 smart_learning_app，但 DB_PASSWORD 登入失敗 | 以前建過這個帳號、密碼不同。把正確密碼填到 `.env` 的 `DB_PASSWORD`；或在 `.env` 把 `DB_USER` 改成新名字（例如 `slp_app2`），腳本會自動建立。 |
| 5013 埠已被其他程式使用 | 系統可能已經開著，直接開 `http://127.0.0.1:5013`；或關掉展示站；或在 `.env` 加 `APP_PORT=5020` 換埠號。 |
| 無法自動更新 | 沒網路，或自己改過檔案。需要最新版時先處理自己的修改，再執行 `git pull`。 |
| 首頁是舊版 | 停在 `main` 分支，照第二節「切換分支」做。 |
| 套件安裝失敗 | 多半是網路中斷，重新點一次即可。仍失敗時把黑色視窗的紅字截圖給組長。 |
| 視窗中文變亂碼 | 在黑色視窗標題列按右鍵 → 內容，字型改為「Consolas」或「新細明體」。不影響功能。 |
| 畫面出現資料表欄位錯誤 | 先 `git pull` 再重開腳本（會自動跑遷移）。仍有問題可在 `.env` 把 `DB_NAME` 改成新名字，建一個全新的資料庫。 |

## 五、不用資料庫的展示站

只想看畫面、做簡報截圖、不想裝 MySQL 時，可在專案資料夾執行下面指令（需先跑過一次 `start_system.bat` 建好 `.venv`）。它用記憶體裡的合成資料，關掉就消失，帳號 `student_demo`／`teacher_demo`／`staff_demo`／`admin_demo`，密碼 `demo2026`：

```bash
.venv\Scripts\python.exe scripts\run_local_demo.py
```

可加參數：

- `--ocr`：改用本機真實 OCR（需先執行 `.venv\Scripts\python.exe scripts\download_ocr_models.py` 下載模型）。
- `--gpu 1`：用顯示卡加速（需安裝 `onnxruntime-directml`；筆電的 0 多半是內建顯示，獨立顯示卡常是 1）。
- `--google`：開放「自傳在 Google 文件中編輯」（需在 `.env` 填 Google OAuth 設定）。

展示站和一鍵啟動都用 5013 埠，不能同時開。

## 六、手動逐步啟動（除錯用）

MySQL 已經在跑（XAMPP Control Panel 按 MySQL 的 Start）時，可以只跑第二節表格的步驟 4～7：

```bash
.venv\Scripts\python.exe scripts\start_local.py
```

## 七、可調整的設定（`.env`）

| 設定 | 用途 | 預設 |
| --- | --- | --- |
| `APP_PORT` | 系統網址埠號 | 5013 |
| `DB_PORT` | MySQL 埠號 | 3306 |
| `DB_NAME`／`DB_USER`／`DB_PASSWORD` | 資料庫名稱與專案帳號 | 第一次自動建立 |
| `MYSQL_ROOT_PASSWORD` | XAMPP root 有設密碼時才填 | 空白 |
| `ADMIN_DEFAULT_PASSWORD` | 第一次建立 `admin` 的密碼 | `admin123` |
| `DOCUMENT_ANALYSIS_PROVIDER` | `fake` 模擬 OCR、`rapidocr` 本機真實 OCR | `fake` |
| `XAMPP_HOME`（系統環境變數） | XAMPP 不在 C:～G: 的 `\xampp` 時指定位置 | — |

`.env` 內含密碼與金鑰，**不要傳給別人、不要提交**；要分享設定請改 `.env.example`。`admin123`、`demo2026` 只是本機測試用的預設值，系統若要開放給別人連線，先改掉。
