# AI 會議室公開會議記憶庫與團隊同步設計規格

- 日期：2026-10-10
- 狀態：已依確認設計完成「歷史快照優先、專案路徑 fallback」實作；公開 `meetings/` 推送仍需人工檢查與使用者另行授權
- 決策：使用者確認將 `meetings/` 整包納入公開 GitHub，供開發者研究 AI Team 會議模式與共同記憶。

## 目標

讓 `ai-meeting-room` 的 GitHub clone 能直接攜帶完整會議記憶：議題、逐字發言、附件、AI 原始 CLI 輸出與會議狀態。其他開發者可以研究 AI 如何互相監督、頭腦風暴及形成專題決策，而不需要依賴原作者電腦上的 `meetings/`。

## 公開範圍

### 納入 GitHub

- `meetings/<meeting-id>/meta.json`
- `meetings/<meeting-id>/messages.jsonl`
- `meetings/<meeting-id>/raw/`
- `meetings/<meeting-id>/uploads/`
- 會議所需的程式、測試、README 與公開開發文件

### 不納入 GitHub

- `workspaces/`：每場專題快照可能很大，也可能含專題原始碼；舊會議的檔案面板只在本機有對應快照時能完整預覽。
- `settings.json`：本機專案路徑。
- `agents.json`：個人 AI 設定與自訂指令。
- `quota.json`：個人額度資料。
- CLI 使用者目錄、登入狀態、API key、`.env`。

公開前的必要檢查：`meetings/` 不得含金鑰、Cookie、密碼、`.env`、私人個資或不應公開的附件。因使用者選擇公開整包，這不再由 `.gitignore` 自動保護，推送前必須人工檢查。

## 啟動與跨電腦行為

組員 clone 後：

1. 安裝 Python 與可用的 AI CLI。
2. 執行 `python -m pip install -r requirements-document-preview.txt`。
3. 啟動會議室。
4. 左側會議列表會讀到 GitHub 帶下來的 `meetings/`。
5. 查看完整對話與 `raw/` 查證資料不需要原作者的登入狀態。
6. 若要讓 AI 針對自己的專題程式碼發言，仍須在本機建立新快照；舊會議的 `meta.json` 內路徑不可直接當成另一台電腦的有效路徑。

## 實作內容

1. 從 `.gitignore` 移除 `meetings/` 忽略規則，加入公開目錄說明與必要的 `.gitkeep`／追蹤檔案。
2. 啟動時不再假設 `meetings/` 一定是空的；保留既有會議並正常排序顯示。
3. 讀取已提交會議時，若 workspace 不存在，會議文字與 raw 仍可讀；檔案面板顯示「此場快照未隨公開會議庫提供」的明確提示，不把它誤判成資料遺失。
4. README 補上「公開會議庫」警告、clone／pull 流程與 workspace 限制。
5. 測試涵蓋：公開會議可列出、缺 workspace 時訊息可讀、原始輸出仍可查看、個人設定未被加入 Git。
6. 開發日誌與代理工作佇列追加本次公開範圍、驗證結果及推送前人工檢查。
7. 檔案面板以歷史 `workspaces/<meeting-id>` 優先；缺少快照時驗證 `meta.json.repo`，可在固定的 `D:\democase` 專案結構下預覽目前專案。
8. fallback 只用於檔案面板、原始檔下載與讀取證據；AI 發言仍固定讀隔離快照，避免 AI 直接接觸目前專案根目錄。

## 驗收標準

- 新電腦 clone 後可在左側看見已提交的會議。
- 會議標題、主題、所有 messages 與 raw 查證內容可讀。
- 缺少舊 workspace 不會讓整場會議消失或讓伺服器初始化失敗。
- 新電腦仍能建立自己的會議與 workspace。
- `meetings/` 內沒有被意外排除；`settings.json`、`agents.json`、`quota.json` 仍不會被提交。
- 專案測試全部通過，並完成公開資料人工檢查清單。

## 已知取捨

- 公開完整 raw 會讓 repo 變大，也可能包含 AI CLI 的完整上下文；這是使用者為了開發者研究與共享記憶明確接受的取捨。
- 舊會議若沒有公開 workspace，檔案面板會改顯示 `meta.json.repo` 指定的目前專案，並在面板提示這不是歷史快照；若另一台電腦沒有相同 `D:\democase` 結構，則只能查看會議文字與 raw。
- 此變更只處理 `ai-meeting-room` 的公開會議庫，不會自動把專題 `D:\democase\ai` 分支合併或推送。
