# AI 會議室檔案完整查看模式實作計畫

> **給執行代理：** 依序執行每個任務；每個任務都要先寫失敗測試，再做最小實作，完成後執行該任務的驗證。

**目標：** 在 AI 會議室檔案面板加入類似 Codex 的沉浸式完整查看模式，讓展示、檔案預覽與後續標注功能有足夠空間。

**架構：** 沿用現有 `static/index.html` 的三欄布局與 `fp` 檔案面板狀態，不新增前端框架。完整模式以 `body.fileFocus` 控制，暫時隱藏左右欄與檔案面板外框，只放大現有檔案預覽；檔案分頁、目錄、來源提示、AI 讀取證據與目前檔案狀態全部沿用。狀態只保存「上次是否完整模式」，不改寫檔案與會議資料。

**技術：** Python 內建 HTTP 伺服器、原生 HTML/CSS/JavaScript、pytest 靜態檢查。

**規格來源：** 使用者 2026-10-10 對 AI 會議室檔案區的 Codex 式完整查看與後續標注需求；本計畫只實作完整查看模式，標注資料模型與 AI 傳遞另立後續計畫。

## 全域限制

- 不修改原始檔案內容，不把預覽操作寫回專案檔案。
- 不呼叫 AI，不消耗任何模型額度。
- 不改變現有檔案 API、歷史快照優先與目前專案 fallback 規則。
- `Esc` 在完整模式只退出完整模式；若同時有圖片燈箱，優先由燈箱處理。
- 原有三欄模式、窄視窗浮層、檔案分頁、下載與新分頁功能都要保留。
- 所有介面文字使用繁體中文，按鈕必須有 `title` 與 `aria-label`。

### 任務 2：加入完整查看模式的介面與狀態切換

**檔案：**
- 修改：`ai-meeting-room/static/index.html` 的檔案面板 CSS、`#filePanel` 標記與檔案面板 JavaScript。
- 測試：`ai-meeting-room/tests/test_layout_and_preview.py`、`ai-meeting-room/tests/test_topic_header.py`

**介面：**
- `toggleFileFocus(on: boolean)`：切換 `body.fileFocus`、保存 `fileFocus` 偏好並更新按鈕狀態。
- `fileFocusExit`：退出完整模式並返回原本檔案面板，不關閉會議或檔案分頁。
- `#fileFocus`：完整模式入口，放在 `.fpHead`，文字為「⛶ 完整查看」。

- [ ] **步驟 1：在檔案面板標題列加入入口與退出按鈕**

入口放在 `#fpTreeBtn` 與 `#fpTabs` 旁；退出按鈕放在完整模式專用的固定工具列，兩者都需有 `type="button"`、`title`、`aria-label`。

- [ ] **步驟 2：加入 CSS 完整模式布局**

加入下列行為：

```css
body.fileFocus #filePanel { position:fixed; inset:0; z-index:60; width:100% !important; min-width:0; border:0; }
body.fileFocus #filePanel .fpBody { min-height:0; }
body.fileFocus main, body.fileFocus aside.left, body.fileFocus aside.right,
body.fileFocus #leftResize, body.fileFocus #rightResize, body.fileFocus #fileResize { display:none; }
body.fileFocus #filePanel #fpView { flex:1; min-width:0; }
```

保留 `.fpHead`、`#fpSide`、`#fpTabs`、文件預覽內部滾動，不可讓整個頁面 `body` 出現第二條不必要捲軸。

- [ ] **步驟 3：實作 `toggleFileFocus`**

函式需：

1. 切換 `document.body.classList.toggle("fileFocus", on)`。
2. `prefs.set("fileFocus", on ? "1" : "0")`。
3. 更新入口的 `on` class 與 `aria-pressed`。
4. `on=true` 時確保檔案面板已開啟；沒有目前檔案時顯示既有空狀態，不自動讀取未知檔案。

- [ ] **步驟 4：接上退出與初始化**

`#fileFocusExit.onclick = () => toggleFileFocus(false)`；啟動時若 `prefs.get("fileFocus") === "1"`，只有在 `filesOpen === "1"` 時恢復完整模式，避免啟動後空白遮罩蓋住會議室。

- [ ] **步驟 5：執行任務 1 測試與布局靜態測試**

執行：

```powershell
python -m pytest tests/test_layout_and_preview.py tests/test_topic_header.py -q --basetemp=D:\democase\pytest-tmp-file-focus-layout
```

預期：所有測試通過。
