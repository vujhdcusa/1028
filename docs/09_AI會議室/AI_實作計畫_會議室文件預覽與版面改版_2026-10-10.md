# AI 會議室文件預覽與版面改版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 支援常見文件格式的可預覽文字抽取，並讓左側會議列、中央檔案面板與右側與會者列可收合、穩定拖曳且不造成對話區跑版。

**Architecture:** 保留原始上傳檔案，新增以副檔名分類的文件抽取邊界；檔案面板使用統一的 preview 結果顯示來源位置，解析器缺少或檔案損壞時回傳可見錯誤。前端以 CSS grid/flex 的三欄容器與獨立 resize handle 管理寬度，收合與寬度存入既有 prefs。

**Tech Stack:** Python 3.10+ 標準庫、可選文件解析套件（pypdf、python-docx、openpyxl、python-pptx、odfpy）、原生 HTML/CSS/JavaScript、既有 Python 靜態檢查。

**Spec:** 本次對話中已確認的「文件預覽＋三欄版面管理＋拖曳布局修正」設計。

## Global Constraints

- 不修改或覆蓋使用者上傳的原始檔案。
- 不把缺少解析器當成空白成功；必須顯示明確的可操作錯誤。
- 保留原始檔下載與新分頁功能。
- 新增 Markdown 僅放在 `D:\democase\ai\docs`。
- 不合併、不推送、不執行 migration。
