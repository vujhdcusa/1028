## 與學校正式規格的差異及待決議事項

正式依據仍是 `D:\democase\ai\docs\01_正式規格\`；本 V2 為使用者選定的開發目標，但文件自己也明載尚待老師與組員審查。

1. 正式規格的 MVP、12 月審核、Phase 2 與 Future 是學校交付切分；V2 的 V1-MUST／SHOULD／V2 是新提案切分，兩套分類不可互相代換。期中 70% 分母須由老師確認。
2. V2 將 Drive 測試整合列為 V1-MUST；目前只有展示原型和本機替身，缺測試帳號、OAuth、真實 Drive API 與 MySQL `file_id` 儲存證據，因此未完成這項 V1-MUST 的實機驗收。
3. 正式規格把紙本 OCR 與學校資料匯入列入 12 月審核；V2 將 OCR／人工確認提前到 V1-MUST。現況只有本機模擬辨識與確認流程，真實 OCR 仍須確認本期優先度。
4. 正式規格列出自傳小幫手、備審產出及導師送審流程；V2 要求 `evidence_id` 和 Evidence Package。這次新增的 ID 是本機追溯補強，不代表已核准外部 AI 傳輸或 Google Docs 流程。
5. 正式規格把班級統計列在 Phase 2；V2 將基本統計列 V1-SHOULD。需由組員／老師決定優先度與驗收分母。
6. V2 的商用多租戶、跨校隔離和授權功能不會因報告提案自動進入本期規格；任何校務資料或 Workspace 導入都要先決定資料擁有權與管理責任。
