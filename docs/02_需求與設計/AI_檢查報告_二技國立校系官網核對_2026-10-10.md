# 檢查報告：二技國立校系官網核對（Gemini 整理版 vs 官網）

- 日期：2026-10-10
- 作者：Claude Code
- 來源：技專校院招生策略委員會 <https://www.techadmi.edu.tw/>「招生資訊查詢 → 二技」，各管道的學校頁（頁面標示 **115 學年度**）。用 `scripts/scrape_techadmi_national.py` 抓取，只讀公開網頁。
- 用途：使用者請 Gemini 整理國立二技校系，覺得有漏；本報告以官網逐校核對。

## 一、結論

1. **Gemini 版本錯很多，不能直接用**：名額大多不對，也列了官網沒有的科系，還漏掉雲科大、高科大、中科大資管與資工等。
2. **官網只有「系名＋名額＋日程＋簡章連結」，沒有備審加權**。系統的缺件分析需要加權，所以新校系要再讀各校簡章才能放進系統。
3. 北科大不在任何一個二技管道的名單上（官網頁尾的北科大地址是招策會辦公室，不是招生學校）。
4. 對資管科學生最重要的國立資管相關系：
   - 技優甄審：臺中科大資管（5）、資訊應用菁英班（10）、資工（8）；臺北商大資管（4）
   - 技優保送：雲林科大資管（2）
   - 日間部申請入學：**雲林科大資管（52）**、臺中科大資管（40）、資工（46）、臺北商大資管（31）
   - 進修部申請入學：臺北商大資管（52）、勤益科大資管（20）

## 二、Gemini 版本的主要錯誤（舉例）

| 管道 | Gemini 寫的 | 官網 |
| --- | --- | --- |
| 技優甄審 | 臺中科大只有護理、美容 | 有 14 個系，**沒有護理**；含資管、資應菁英班、資工 |
| 技優甄審 | 臺北商大有應用外語系（4） | 沒有；資管是 4 名（Gemini 寫 3） |
| 技優甄審 | 臺北護理健康大學「高齡健康照護系」 | 沒有這個系；有長期照護、嬰幼兒保育等 7 個 |
| 技優甄審 | 高雄餐旅有旅館管理、航空 | 只有餐飲管理（1） |
| 日間部 | 臺科大應外 45、北護護理 300 以上 | 23、242 |
| 日間部 | 臺北商大企管 43、財金 44 | 29、34 |
| 日間部 | 沒有雲林科大 | 雲林科大資管 52、企管 30 |
| 進修部 | 屏東科大企管、農企各 40 | 只有社會工作系（26） |
| 技優保送 | 雲科企管、工工；北商；虎尾機械 | 只有雲林科大資管（2） |
| 產學攜手 | 高雄餐旅餐飲專班 | 只有臺北護理健康大學護理系在職專班（50） |

Gemini 另外附的「技優甄審優待加分表」（乙級 +15% 等）**官網這幾頁沒有，未核對**；系統目前也沒有用到加分比率，先不採用。

## 四、系統用不用得到

| 資料 | 用途 | 做法 |
| --- | --- | --- |
| 系名、名額、管道 | 「資料爆多 → 聚焦」展示、二技公告、一年級認識學校 | 可以用；名額是公開資料 |
| 備審加權 | 缺件分析、準備度、AI 推薦 | 官網沒有，要讀各校簡章（下載前先問使用者） |
| 加分比率 | 目前沒用到 | 不採用 |

目前系統只有技優甄審的加權（PDF 整理）。若要放日間部申請入學（人數最多、雲科資管在這），需要雲科大、臺中科大、臺北商大等的簡章。
