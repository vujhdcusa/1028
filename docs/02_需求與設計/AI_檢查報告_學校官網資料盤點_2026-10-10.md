# 檢查報告：學校官網資料盤點（資管科、學校官網、資圖中心）

- 日期：2026-10-10
- 範圍：資管科 <https://im.ukn.edu.tw/>、學校官網 <https://www.ukn.edu.tw/app/home.php>、資訊暨圖書中心 <https://ils.ukn.edu.tw/>
- 方法：Claude 讀首頁選單與約 20 個子頁的文字（只讀、不存原始頁面，每頁間隔 2 秒）；修業科目表 PDF 另外下載到 `school/public-sources/修業科目表/`。
- 目的：找出資管科小助手、引導卡片、推薦校系、畢業學分檢查可以用的公開資料，並依使用者的想法**在系統內重新分類**（學校網站只有依時間排列的公告列表，沒有分類與搜尋）。
- 注意：公開的「專題初審結果」「比賽得獎名單」可能列有學生姓名。系統只存**標題、日期、連結**，不存名單內容。

## 一、最重要的發現：學校已經有很多系統

學校官網「學生專區」列出全校共用系統，其中和本專題直接相關的有：

| 學校已有的系統 | 和本專題的關係 | 建議 |
| --- | --- | --- |
| 學生資訊系統（成績、獎懲、缺曠查詢） | 資料來源 | 學生複製貼上（已定案），不登入、不爬 |
| **學生證照上傳管理** | 和我們的「上傳證照」重疊 | 不重做學校的證照登錄；我們的重點是**整合進備審資料、對照目標校系** |
| **競賽活動報名系統** | 學校已有 | 符合「競賽報名取消」的決定，不重做 |
| **電子證書發證平台** | 學生下載電子證書後上傳我們系統 | 已規劃（讀出驗證碼） |
| 微學分系統 | 微學分的證明來源 | 規格書原本「微學分處理方式待確認」→ 可請學生從這裡下載證明 |
| 服務學習課程記錄 | 服務學習的證明來源 | 可作為「服務學習」類資料的來源說明 |
| 實習週記管理系統 | 實習經歷的來源 | 可作為「實習」資料的來源說明 |
| 課程綱要與歷年教學計畫 | 課程內容 | 小助手回答「這門課在學什麼」的來源 |
| 學習低成就輔導系統 | 補救教學 | 可放進「怎麼操作」說明區的連結 |
| 資管科「畢業專題管理系統」（`oes3.im.ukn.edu.tw/~proj/project/`） | 專題繳交與審查 | **不重做**；我們只收「我負責的部分」等備審需要的內容 |

| **教務處「學生學習歷程系統」** | 和本專題同名 | **已經失效**：教務處選單的連結（<https://daa.ukn.edu.tw/p/450-1021-544,c1.php>）轉到 `http://portfolio.knjc.edu.tw/`，20 秒連不上（2026-10-10 測試）。`knjc` 是學校改名前的舊網域，代表這是很舊、沒有維護的系統 |

**對 11/4 簡報的意義**：評審很可能問「學校已經有這些系統，你們做的有什麼不同？」。答案是：學校的系統各自分散，我們把成績、證照、競賽、服務、實習、專題**整合起來**，對照二技校系的要求，產出備審資料，並由導師確認。這可以放進簡報「和歷屆專題的差別」或「開發動機」。

## 三、在系統內重新分類（使用者的想法）

學校網站只有依時間排列的公告列表。資管科小助手抓回來後，在本系統依下面的方式分類，學生可以像 Discord 一樣點分類瀏覽、搜尋，引導卡片與小助手也從這裡取資料：

| 分類欄位 | 值 |
| --- | --- |
| 主題 | 專題、實習、證照、比賽、課程與畢業、升學二技、學程、行政與表單、系統使用 |
| 適用年級 | 專一～專五（可多選）；例如資訊盃分低年級組、高年級組 |
| 類型 | 公告、規定、時程、比賽報名、證照考試、成果與榮譽 |
| 有效期間 | 公告日期、截止日期；過期的自動收起（不刪除） |
| 來源 | 資管科、學校官網、資圖中心；附原始連結 |

- AI 代理先擬分類，**管理員核對後**才給學生看（和二技公告同一套機制）。
- 引導卡片依「年級＋主題＋還沒過期」挑出要顯示的資料，例如專一學生在資訊盃報名期間看到「資訊盃 OFFICE 比賽開始報名（你是低年級組）」。

## 四、抓取時要注意

1. 學校網站的選單是網頁執行時才載入的，靜態內容抓不到；要從列表頁（`/p/403-...`）和固定頁面（`/p/412-...`、`/p/405-...`）抓。
2. 列表頁只顯示最新約 12 則，舊的要翻頁。
3. 附件多是 PDF、DOC，只在需要時下載單一檔案，不整批下載。
4. 名單類公告（初審結果、得獎名單）只存標題、日期、連結，不存學生姓名。
5. 頻率低（每天或每週一次），每頁間隔幾秒。

## 五、建議放進規格的事

1. 二技公告的「資料來源 Agent」擴充成三類來源：二技招生、資管科官網、資圖中心（已在 `AI_設計規格_學校資料匯入與官網資料來源_2026-10-10.md` 第五節）。
2. 新增「資料分類」功能（第三節），給學生瀏覽與搜尋、給引導卡片與小助手使用。
3. 引導卡片加上：證照地圖對應的「這學期可以準備的證照」、資訊盃報名（依年級分組）、實習成果報告書與專題時程提醒。
4. 推薦校系與一年級認識科系：用「資訊軟體開發／資訊軟體應用」兩個模組說明方向。
5. 11/4 簡報說明「學校已有系統」與本系統的差別（整合與備審）。
