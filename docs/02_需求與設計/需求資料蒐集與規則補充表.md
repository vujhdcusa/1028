```
校內轉科：**保留原學號與帳號**，僅更新轉入後的科系、班級或學籍狀態；不依轉入班級重新推算或改寫學號。

校外轉入：學校賦予新的校內學號與帳號；如有原校成績單、抵免或免修資料，應以附件與人工確認結果保留，不依學號格式自行推斷前校資料。
休學：停用帳號，但休學期間保留入學紀錄
復學：保留該年度入學紀錄，但要將休學期間視為該學生有入學紀錄，若休學時間超過申請休學規定年限(最多只能休學兩年，但如果超過年限則須檢附相關證明文件)，可以
畢業：保留帳號，密碼變成大寫字母
退學：停用帳號，並移除帳號，但在退學前1個月跳系統通知提醒，同時也會寄信到學校信箱通知，並請學生輸入個人信箱，把作品集打包成壓縮檔案的下載連結寄到學生個人信箱。
```

### 6.3 AI Agent 不可直接做什麼

- 不可直接修改正式畢業門檻。
- 不可直接判定學生畢業或不及格。
- 不可沒有來源就補寫校方規定。
- 不可將搜尋結果直接發布成正式規則。
- 不可核准或退回行政申請、核定抵免資格／學分、覆寫已發布表單或學生原始附件。
- 不可讀取需要帳號密碼的私人資料，除非學校正式授權介接。

人工確認流程：

```
Agent 蒐集來源 → 產生草稿 → 顯示來源與差異 → 管理員／科辦確認
→ 發布正式版本 → 保留發布人、時間與原始來源
```
