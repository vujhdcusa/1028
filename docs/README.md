## 維護規則

- 新增正式規格前，先判斷應放入哪一個分類資料夾。
- 舊文件不直接刪除，改放入適當的歷史或封存位置並在此索引註明。
- 修改文件後，應同步更新 `03_開發紀錄/development-log.md`。
- `.env`、密碼、Token 等機密不得寫入本索引。
- 封存文件不得作為現行規格唯一依據；以現行版索引與最新交接文件為準。
