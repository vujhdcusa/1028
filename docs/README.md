## 維護規則

- AI 產生的 Markdown 一律放 `docs/` 的**子資料夾**（不要放最上層），檔名加前綴（`AI_設計規格_`、`AI_實作計畫_`、`AI_檢查報告_`、`AI_交接_`）。
- 舊文件**不刪除**，搬到 `99_封存_歷史與待確認/` 對應的子資料夾，並修正其他文件的連結。
- 每次修改都要寫開發日誌，**最新的寫在最上面**。
- `.env`、密碼、金鑰不得寫進任何文件。
