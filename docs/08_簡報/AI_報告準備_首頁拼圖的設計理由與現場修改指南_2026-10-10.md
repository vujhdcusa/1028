# 報告準備：首頁拼圖的設計理由與現場修改指南

- 日期：2026-10-10
- 用途：口試或審查時，老師問「為什麼做拼圖」「現場改一下」時用。內容只寫系統真的有做的事。

## 一、老師問「為什麼做拼圖？」可以這樣回答

> **一句話**：學生一年只用一次系統，我們要讓他一打開就看到「今年還差什麼」，而且不是用紅字警告，是用一張還沒拼完的圖。

1. **每一片都對應真的資料，不是裝飾**：六片＝成績、證照、活動、競賽、服務、幹部，就是二技書審會看的六類資料。洞就是今年還沒有的那一類；把那片拖回洞裡，就會打開那一類的新增頁。
2. **缺漏看得見，但沒有壓力**：五專生要連續用五年。一直顯示「缺件！未完成！」會讓人不想打開；人看到拼圖缺一塊，會自然想把它補起來。（設計討論紀錄：`docs/99_封存_歷史與待確認/04_視覺參考與聊天紀錄/…/chat.md` 第 9 輪「缺漏也成為視覺的一部分」）
3. **照片是自己的**：拼圖的圖是學生上傳的「這學期最快樂的照片」，拼完就是一張自己的回憶，五年後有 10 張。這讓學生願意每學期回來。
4. **兼顧隱私**：照片只有本人看得到，不放進備審、不給 AI、不給老師；上傳時會去掉照片裡的拍攝地點等資訊。
5. **熟悉的人不用玩**：上方選單一直都在，可以直接點，不用每次拖拼圖。

可能的追問：

| 追問 | 回答 |
| --- | --- |
| 拼圖片數為什麼是 6？ | 對應六類學習資料（`journey_service.CATEGORY_KEYS`）。 |
| 這片怎麼判斷算「拼上」？ | 今年的資料夾裡那一類至少有一筆（`journey_home.py` 的 `filled`）。 |
| 照片存在哪？資料庫要不要改？ | 不改資料庫；存成檔案 `uploads/semester-photos/學生編號/年級-學期.jpg`。 |
| 上學期、下學期怎麼分？ | 8 月～1 月是上學期，2～7 月是下學期（`photo_service.current_semester`）。 |
| 手機可以拖嗎？ | 用的是 Pointer Events，滑鼠、觸控都可以；不想拖也可以直接點。 |

## 二、老師要你「現場改一下」：去哪裡改

先打開這兩個檔案就能處理大部分要求：`app/services/journey_home.py`（資料）、`app/templates/student_home.html`（畫面）。改完重新整理網頁；展示版若沒開偵錯模式，改範本要重開伺服器。

| 老師說 | 改哪裡 | 怎麼改 |
| --- | --- | --- |
| 「標題字改一下」 | `student_home.html` 搜尋 `還差` | 直接改中文字 |
| 「拼圖的類別名稱換一下」 | `journey_home.py` 的 `PIECE_LABELS` | 改字典裡的中文 |
| 「多久沒登入才顯示好久不見？」 | `journey_home.py` 的 `RETURN_DAYS = 60` | 改數字 |
| 「拼圖凸出的方向換一下」 | `journey_home.py` 的 `H_TABS`、`V_TABS` | 把 1 改成 -1 |
| 「凸出大一點」 | `journey_home.py` 的 `_edge()` 裡 `h = PIECE * 0.22` | 改 0.22 |
| 「顏色換一下」 | `app/static/css/design-system.css` 最上面的 `--year-1`～`--year-5` | 改色碼 |
| 「上下學期的月份」 | `photo_service.py` 的 `current_semester()` | 改月份判斷 |
| 「拖多近才算放進去？」 | `app/static/js/components.js` 搜尋 `a.width * 0.35` | 改 0.35（越大越好放） |
| 「動畫快一點」 | `design-system.css` 搜尋 `jig-in`、`route-draw` | 改秒數 |
| 「小人物走慢一點」 | `components.js` 搜尋 `900 + (grade - 1) * 450` | 改毫秒數 |

建議事前在自己電腦練習 2～3 次：改字、改顏色、改 `RETURN_DAYS`，改完跑一次測試：

```
D:\democase\ai\.venv\Scripts\python.exe -m pytest tests/test_journey_home.py tests/test_semester_photo.py -q
```
