## 1. 本次設計要解決的事

本系統不是另一個「上傳檔案、下載檔案」的網站，而是協助五專資管科學生從專一到專五，將課程、作品、證照、競賽、專題、實習與反思整理成可回看、可使用、可前往下一站的個人學習歷程。

首頁必須同時讓三種人看懂：

- 國三生與家長：五專資管不只是讀書，而是在五年內逐步累積可被看見的能力與選擇。
- 學生：我現在有哪些成果、缺少什麼、下一步可以整理什麼。
- 教師與評審：這不是單純美化的招生頁，而是視覺設計真的接到資料、作品集、證照、專題與未來規劃。

不使用「保證考上國立大學」「遙遙領先其他學生」等無法證明的說法。系統要表達的是：**學生能更早開始累積、整理與呈現自己的選擇。**

## 2. 已確認的視覺世界觀

### 2.1 四個視覺語言

| 元素 | 代表意義 | 實際功能 |
|---|---|---|
| 檔案 Archive | 五年資料原本散落、後來被收納 | 年級檔案、成果收納、佐證附件 |
| 路徑 Path | 專一到專五，以及下一站 | 五年地圖、升學／職涯進路 |
| 拼圖 Piece | 一件已被整理的能力或成果 | 互動作品集、完成度、缺漏引導 |
| 聚焦 Focus | 依目前目標突出重要資料 | 升學目標、職涯方向、AI 整理建議 |

### 2.2 氣質比例

- 70% 安靜、成熟、耐看。
- 20% 雜誌式資訊編輯與藝術構圖。
- 10% 有意義的互動驚喜。

不是一般科技藍 Dashboard、不是手遊闖關、不是 AI 紫色漸層網站。

### 2.3 視覺素材使用原則

`assets` 資料夾中的範例圖僅作為構圖、材質、動畫與資訊層次的靈感，**不得直接放入正式網站**。正式網站要以自製 SVG、CSS、原創插畫或具授權素材重做。

## 3. 首頁完整故事分鏡

### 第一幕：檔案海——五年會留下很多東西

**參考構圖：** `assets/img-003.jpg`  
**主文案：**

> 五年，會留下很多東西。
>
> 課程、作品、證照、競賽、專題與實習。  
> 但真正重要的，不只是把它們留下。

**畫面：** 米白或霧白背景。大量單色、原創檔案夾向遠方延伸；中央只有一名抽象學生剪影或一個被留白的「我」的位置。使用深藍搭配非常少量亮色，避免彩色卡片堆滿畫面。

**動畫：** 捲動時只有細微景深與遠近位移；不做大量飛行特效。使用者先感受到「資料很多」，而不是先被功能說明轟炸。

---

### 第二幕：資料隊列——留下只是第一步

**參考構圖：** `assets/img-009.jpg`  
**主文案：**

> 留下，只是第一步。
>
> 整理，才能成為下一次選擇。

**畫面：** 從檔案海中抽出六種類型的資料：課程成果、作品、證照、競賽、專題、實習。它們形成一條具有深度的資料隊列，如同被抽出、排序、送入檔案庫。

**動畫：** 資料夾不是隨機亂飛，而是沿同一個方向平穩前進；每一張只露出簡短類型與抽象縮圖。這是「資料被理解」的過程，不是視覺特效表演。

---

### 第三幕：五年書籤——資料開始有年份與脈絡

**參考構圖：** `assets/img-006.jpg`、`assets/img-004.jpg`  
**主文案：**

> 每一年，都不是重新開始。
>
> 而是把前一年留下的東西，帶往更遠的地方。

**畫面：** 資料收進一冊大型數位檔案，形成專一、專二、專三、專四、專五五個分層書籤；不做五張相同卡片。每個書籤帶出該年的學習重點與可累積資料。

**基本年級敘事：**

| 年級 | 敘事詞 | 可展示的資料類型 |
|---|---|---|
| 專一 | 起點 | 基礎課程、第一份作品、初階證照準備 |
| 專二 | 累積 | 技能作品、證照、活動與競賽嘗試 |
| 專三 | 找到方向 | 能力盤點、作品整理、進階技能 |
| 專四 | 帶著能力出去 | 實習準備／經驗、專業應用、成果佐證 |
| 專五 | 完成一件事 | 專題、成果發表、升學或就業準備 |

實際規則、截止日與必繳文件必須依學年度設定，不能在首頁寫死。

### 第四幕：不只讀書，也做出能力

**參考構圖：** `assets/img-005.jpg`  
**給家長與國三生的主文案：**

> 不只準備考試，  
> 也開始準備下一站。

**補充文案：**

> 五年裡，孩子不只讀書。  
> 他會把學到的東西，做成看得見的能力。

**畫面與動畫：** 起初是一片相似的蜂巢格；接著其中一條成長路徑長出「課程、作品、證照、競賽、專題、實習」等不同格子，最後接上未來方向。

**不可使用的說法：**「遙遙領先」「保證升學」「比別人強」。  
**要表達的意義：** 學生不是被迫提早決定人生，而是更早累積能夠選擇未來的能力。

### 第五幕：我的五年拼圖——成果不是散件

**參考構圖：** `assets/img-020.jpg`  
**主文案：**

> 每一件留下的東西，  
> 都是你下一站的一塊拼圖。

**定位：** 拼圖不是可愛遊戲，也不是「一張證照一塊拼圖」。它是一幅成熟的、可互動的個人能力作品集。

**第一層大型拼圖分類：**

1. 課程與學習成果
2. 作品集
3. 證照與技能
4. 競賽與活動
5. 專題歷程
6. 實習經驗
7. 個人反思
8. 下一站準備

**點擊行為：** 點一塊大型拼圖後，不是跳出空洞統計，而是打開該類成果的「佐證資料夾」。

| 點擊類別 | 開啟資料 |
|---|---|
| 證照與技能 | 證書、取得日期、證照類型、驗證狀態、學習反思 |
| 競賽與活動 | 比賽名稱、團隊角色、獎狀、作品／照片、心得 |
| 作品集 | 作品故事、本人角色、使用技術、成果連結、截圖 |
| 專題歷程 | 共同成果連結、個人分工、Q&A、反思、最終審查結果 |
| 實習經驗 | 準備資料、實習佐證、工作內容、學習紀錄 |

**缺漏設計：** 不出現大量紅字。以淡色空拼圖表示「這一塊還可以留下什麼？」；點擊後直接引導使用者新增適當佐證。只有真正的截止日或資格風險才使用警示色。

**公開隱私：** 學生的拼圖作品集預設為本人與授權教師可見。要公開分享給家長、升學或就業使用時，必須由學生主動選擇可公開項目。

### 第六幕：資管人的下一站地圖

**參考構圖：** `assets/img-007.jpg`  
**主文案：**

> 五年不是終點。  
> 是你開始選擇下一站的地方。

**結構：** 借用「可探索地圖」的概念，不照抄原圖的銀行插畫或大量說明文字。由五年拼圖向外長出三條主路。

```text
                    我的五年拼圖
                         ↓
               ┌─────────┼─────────┐
             升學       軟體開發       資訊應用
          二技／插大    系統／網頁      電商／資料／行政
```

### 6.1 升學方向

- 首頁僅介紹「二技、插大、出國進修等」可能路徑。
- 學生登入後才能建立自己的目標校系，例如想準備的國立二技校系。
- 系統顯示的是成果整理狀態與可補充佐證，不產生錄取率，也不承諾錄取。
- 招生條件、採認規則、目標校系資料必須由可信來源確認，並保留更新日期。

### 6.2 就業方向

依康寧資管科官網職涯進路，首頁可先以兩個易懂的群組呈現：

- **資訊軟體開發：** 系統開發、網頁程式、資料庫、系統測試、資訊硬體等。
- **資訊軟體應用：** 電子商務、網路行銷、企業資訊助理、資料處理／分析、網頁設計等。

職稱與推薦證照不能永久寫死，應由科辦依學年度或公告維護。

### 6.3 聚焦模式

選擇「網頁設計」「電子商務」「某一升學目標」後，作品、證照、競賽、專題與實習拼圖中相關的區塊亮起，其他資料仍保留但降低存在感。

範例：

```text
網頁設計人員
已累積：網頁作品、程式課程、相關證照
可以補強：作品說明、個人角色、專題成果
可檢視：3 件作品／1 張證照／1 段專題紀錄
```

AI 在此只能協助「聚焦、提示與整理」，不得替教師做判定，也不得自行決定學生適合什麼職涯。

## 4. 動畫規格：有故事，不炫技

| 互動 | 動畫目的 | 製作方式建議 |
|---|---|---|
| 檔案海景深 | 讓人感受資料量與留白 | CSS transform、少量 SVG 分層 |
| 資料進隊列 | 表達收納與整理 | 依捲動進度移動既有資料類型 |
| 五年書籤拉出 | 表達年級脈絡 | CSS／SVG 頁籤位移與內容替換 |
| 拼圖扣合 | 表達成果被整合 | 短暫、一次性的對位動畫 |
| 職涯地圖長出路徑 | 表達「成果可通往下一站」 | SVG path stroke 動畫與點擊聚焦 |
| 聚焦 | 表達目標下的選擇 | 非相關項目降低透明度，相關項目亮起 |

### 4.1 必守限制

- 不做難以維護的大型 3D 遊戲場景。
- 不用影片假裝互動；關鍵資料要能真實點擊與對應系統資料。
- 每段動畫皆要支援 `prefers-reduced-motion`，可改成靜態漸顯與直接跳轉。
- 手機版保留故事順序，但改為直向堆疊；不硬塞桌面透視畫面。
- 動畫不能拖慢老師與行政的工作流程。

## 5. 體驗層與工作層分工

| 層級 | 頁面 | 視覺重點 |
|---|---|---|
| 體驗層 | 公開首頁、學生首頁、我的五年、拼圖作品集、下一站地圖、畢業頁 | 大留白、編輯設計、路徑、拼圖、溫和動畫 |
| 工作層 | 資料新增、佐證上傳、教師檢視、行政設定、審查紀錄 | 搜尋、篩選、表格、清楚狀態、少量品牌元素 |

教師與行政不應被迫使用藝術化介面；但學生明細頁可以有小型五年地圖，讓教師先理解學生的累積輪廓，再進入表格與佐證檔。

## 6. 視覺基調與元件規則

### 建議色彩

- 基底：紙張米白、霧白、淺灰藍。
- 主色：深墨藍或鈷藍。
- 強調色：只選一種作為頁面主角，例如檸檬黃、珊瑚紅或青藍；不可同時大量使用粉、黃、藍、綠。
- 完成：低飽和綠色；提醒：琥珀色；錯誤與截止風險才使用紅色。

### 版面

- 一個畫面只保留一個主視覺語言。
- 使用非常大的留白與標題，不以滿版卡片製造「資訊很多」的假象。
- 採雜誌式大標、細小說明、精準對齊；避免每個區塊都有圓角、陰影與圖示。
- 教師／行政區回到耐看的工作台，不使用大型插畫干擾查閱。

## 7. 期中核心與正式完整版

### 期中可展示的核心

1. 原創檔案海公開首頁首幕。
2. 五年書籤／五年路徑。
3. 可點擊的拼圖作品集，至少支援作品、證照、競賽三類。
4. 一個「下一站」聚焦範例，例如網頁設計職涯或指定升學目標。
5. 學生新增佐證、教師查看學生資料的基本真實流程。

### 正式完整版再加入

- 年度時間膠囊：每年挑選值得留下的三至五件成果。
- 完整職涯地圖與可維護職稱／證照規則。
- 個人公開作品集與分享權限。
- 專五畢業總結頁：「你的五年，整理好了。」
- 更細緻的捲動動畫與個人資料視覺化。

## 9. 後續設計順序

1. 先依本分鏡製作兩張高品質靜態視覺稿：首頁首幕、學生拼圖作品集。
2. 確認色彩、字體、插畫風格後，再製作 HTML／CSS 原型。
3. 將拼圖分類、證照資料、職涯分類對接既有資料表與學年度規則。
4. 最後才加入捲動、點擊與聚焦動畫；不能先做動畫再補功能。
